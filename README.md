# HR-Recht Radar Schweiz

Wöchentlicher Newsdienst zu Arbeitsrecht, Bundesgerichtsurteilen, Gesetzgebung, Sozialversicherungen und HR-Praxis in der Schweiz.

- `index.html` – die Webseite (lädt die Inhalte aus `data/news.json`)
- `data/news.json` – alle Meldungen, Ausgaben, Kennzahlen und Termine; wird jeden Montag automatisch aktualisiert

Veröffentlicht über GitHub Pages.
